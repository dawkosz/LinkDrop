# LinkDrop 1.2.1

Windows x64 app with a Polish interface for audio/video downloads, playlists, grouped albums, queue management, persistent history, retries, and local diagnostics.

First run:

1. Extract the complete ZIP.
2. Install .NET 9 Desktop Runtime x64 if needed.
3. Open `Start-LinkDrop.cmd`. It downloads verified media tools directly from their official release providers on first run, then starts the app.

The ZIP excludes third-party engine binaries, private history, local settings, media files, and development reports. Internet access is required to install the tools. The app EXE is unsigned.
